What does this system do?

A sensor measures the soil moisture, temperature, humidity and light around a plant. The system stores these numbers, waters the plant automatically when the soil is too dry, and warns you about problems.

Words explained

Soil moisture: how wet the soil is (0% dry, 100% soaked).
Threshold / watering level: the moisture level below which watering starts.
Alert: a warning message.
Simulator: a program that pretends to be a real sensor so you can try everything without hardware.

Something looks wrong?

“Sensor is not responding”: the sensor or simulator has stopped. Restart the app. Numbers not changing: wait a few seconds; pages refresh every 4 seconds.
